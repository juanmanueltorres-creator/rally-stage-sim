# rally-stage-sim

Open-source rally stage simulator with animated vehicles, timing, weather and terrain context on interactive maps.

> Unofficial project for research, education and visualization. Not affiliated with FIA, WRC Promoter GmbH or event organizers.

## First scenario

**WRC Rally Chile Bio Bío 2026** is the first dataset. The initial foundation starts with SS1 Turquía and intentionally stores no stage geometry until a trustworthy LineString is verified.

Current sourced V0 metadata:

- Event: 10–13 September 2026.
- SS1 Turquía 1: 22.94 km.
- Planned first competition start: 11 September 2026 at 08:53 local time.
- Data state: `planned`.
- Geometry state: `pending-verification`.

## Data rule

The simulator distinguishes three states:

- `planned` — schedule or pre-event information from a named source.
- `simulated` — values generated by our model.
- `observed` — recorded timing, split or telemetry-like information.

Unknown values stay unknown. The UI does not invent a route simply to make the map look complete.

## Stack

- React 19
- TypeScript
- Vite
- MapLibre GL
- Turf.js
- Static JSON snapshots

No backend, database, login or paid API is required for V0.

## Current branch goal

`feat/chile-2026-foundation` establishes the domain contracts, SS1 sourced metadata, pure stage-progress math and a regional Biobío map shell. Vehicle animation comes after verified stage geometry is available.

## Sources

The dataset stores source URLs and access dates beside the values they support. Initial sources are the official WRC 2026 calendar/route announcement and Rally Chile Bio Bío event information.
